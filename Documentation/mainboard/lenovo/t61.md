# Lenovo ThinkPad T61 / T61p

The T61 is part of the `lenovo/crestline_thinkpad` board, together with the
X61. It uses a GM965 northbridge and an ICH8M-E southbridge. Depending on the
model, the display is driven by the integrated graphics or by an NVIDIA GPU on
PEG (Quadro NVS 140M or Quadro FX 570M). coreboot detects which one is
present at boot, so the same image works for both.

## Flash layout

The T61 has a 4 MiB SPI flash chip. The vendor flash layout is:

```
00000000:00000fff fd
00001000:0027dfff me
0027e000:0027ffff gbe
00280000:003fffff bios
```

Under the vendor BIOS, the flash descriptor is read-only and the ME region is
locked, so only the `bios` and `gbe` regions can be written internally. This
leaves 1.5 MiB for coreboot.

## Discrete GPU option ROM

Models with an NVIDIA GPU need its option ROM in CBFS (`VGA_BIOS`). It is not
on the GPU, but in the vendor BIOS. It can be extracted from a backup of the
vendor BIOS region with [bios_extract]:

* `oprom_1.rom`: `10de,0429`, Quadro NVS 140M
* `oprom_0.rom`: `10de,040c`, Quadro FX 570M

Set `VGA_BIOS_ID` to the ID of the GPU of your model.

## Internal flashing

coreboot can be installed from the vendor BIOS without an external programmer.
The vendor BIOS write-protects the top 64 KiB of the flash (PR0), where the
bootblock lives, so this uses the Top Swap feature of the ICH: with the
`BUC.TS` bit set, the CPU boots from the 64 KiB below the top of the flash
instead, which is not protected.

```{eval-rst}
.. warning::
   Always use hardware sequencing (``ich_spi_mode=hwseq``) and a layout file to
   write the flash on this board. With software sequencing, flashrom may choose
   a chip erase to erase a region, which erases the whole chip, including the
   descriptor and the ME region that cannot be written back internally.
```

1. Build coreboot with `INTEL_ADD_TOP_SWAP_BOOTBLOCK` enabled.

2. Make a backup of the regions that can be read:

   ```console
   # flashrom -p internal:ich_spi_mode=hwseq --ifd -i fd -i gbe -i bios -r backup.rom
   ```

3. Write everything but the protected 64 KiB, with this layout file:

   ```
   00280000:003effff bios_below_pr0
   ```

   ```console
   # flashrom -p internal:ich_spi_mode=hwseq -l layout_below_pr0.txt -i bios_below_pr0 -w coreboot.rom
   ```

4. Set the Top Swap bit with [bucts] and reboot. The bit is kept in the
   RTC well, so don't remove the RTC battery until the last step is done.

   ```console
   # bucts --set
   ```

5. Once coreboot booted, the whole `bios` region can be written. Write the
   image again with this layout file, then clear the Top Swap bit:

   ```
   00280000:003fffff bios
   ```

   ```console
   # flashrom -p internal:ich_spi_mode=hwseq -l layout_bios.txt -i bios -w coreboot.rom
   # bucts --unset
   ```

Later updates only need step 5, without bucts.

## Tested

Tested on a T61 7663 with a Quadro NVS 140M, a Core 2 Duo T8100 and 2x 2 GiB
DDR2-667, with SeaBIOS and Debian:

* Display (NVIDIA GPU, with nouveau), brightness keys
* Ethernet, Wi-Fi
* SATA, Ultrabay DVD drive
* HD audio
* S3 suspend and resume
* Internal flashing, as described above

## Not tested

* Models with integrated graphics
* T61p, Quadro FX 570M
* Docking stations

## Not working

* TPM: coreboot doesn't detect it (`pc80_tpm_probe: No TPM device found`)
